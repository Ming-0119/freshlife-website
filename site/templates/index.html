FreshLife AI

从家里已有的食材开始，安排下一餐。

FreshLife AI 从你家现有的库存、临期食材与偏好出发给出建议。本机能力离线可用；远程 AI 当前版本尚未启用，未来上线时默认关闭、由你决定是否开启。

{{ai_modes}}
远程 AI 会处理哪些信息？展开查看数据边界

当前版本（1.0.0）尚未启用远程 AI。未来如果上线，会默认关闭；启用前会说明需要处理的信息并征得你的明确同意，只发送完成当次请求所需的内容。过敏信息、健康目标、个人资料、AI 记忆、餐食与购物历史及长期行为记录，不属于当前规划中的远程 AI 请求内容。服务商 API 密钥不会内置在 App 中，App 也不会要求你提供 API Key。AI 建议仅供参考，不构成医疗建议。
