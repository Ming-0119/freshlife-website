# FreshLife 官网动态体验升级 · 2026-09-12

本轮根据用户 75a17e16 附件实施。此记录不代表历史全部产品要求、四个平台或附件所有验收条件已经完成。

## 已实现

- 中英首屏改为用途与入口 + 库存到购物的原创示例。保留本地数据/未同步说明；样例明确标注，不伪装成用户库存或真实 App 截图。
- 全站 CSS 时长归并为 160 / 220 / 300 ms，曲线沿用 FreshLife App Motion DNA `.2,.7,.2,1`，不是复制第三方参数。品牌颜色、圆角、字体系统保留。
- 首屏文字和 CTA 从第一帧可读，最多 8 px 的短入场；取消整页透明入场、循环漂浮、循环光晕、章节内部逐行错峰。
- 桌面四段故事用同一滚动位置连续交叉淡入。相邻章节中心之间 38%–62% 为交接区域，其他区间稳定展示。权重总和为 1，支持反向、快速跳过和页面恢复。
- 正文不降低透明度；设备仅作内容容器，不旋转。手机/矮屏/大字号使用静态章节示例。
- Hero / header / 阅读进度 / 故事共享事件驱动 rAF。尺寸只在布局变化时读取，无常驻动画循环；后台页面停止更新。
- 设备切换采用可取消的 Web Animations，移除强制 offsetWidth 重排。
- 选项玻璃仅保留在互斥选择器；取消过冲与宽高过渡，保留直接拖动、释放确认、Escape 取消、触屏滚动及键盘操作。
- 系统与站内减少动态效果均可即时生效；关闭后正常恢复。减少动态效果时取消固定舞台，章节成为普通文档流。
- 首屏以下尚未延迟加载的示例图添加 lazy / async；沿用已有尺寸。未新增第三方动画库、追踪 SDK、视频资源或网络功能。

## Motion 角色

|角色|实现|
|---|---|
|fast / scale|160 ms；按压 .985|
|standard / fade / slide / shared|220 ms|
|slow / reveal|300 ms；移动不超过 8 px|
|sticky|仅宽且足够高的桌面舞台，跟随原生页面滚动|
|parallaxSoft|首屏最大 8 px，手机与减少动态效果下为 0|
|scrollLinked|滚动位置驱动相邻屏幕 opacity，无额外时间缓动|
